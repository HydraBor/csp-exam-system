# 题目导出与迁移

管理员在「题库」列表勾选题目，点击「批量导出 ZIP」下载；表头复选框可全选，按钮旁显示已选数量。ZIP 中每题一个独立文件夹，按内部标识区分，避免同名题目互相覆盖。也可点击单题的「导出 ZIP」，或题目详情顶部同名按钮下载。

导出无需停止网站；服务在写锁和数据库事务内读取一致版本，复制到私有临时目录后释放锁，再压缩和流式下载。并发导出限制为一个，忙时返回 429；下载完成或客户端断开后清理临时文件。匿名用户和考生无权访问导出接口。

ZIP 包含本系统实际保存的全部题目材料：内部标识、标题、默认英文名、毫秒时限、MiB 内存、Markdown 题面、已保存的标准程序、全部正式输入和答案、样例及大样例附件，以及逐文件 SHA-256 清单。样例分类、标签、文件角色、原文件名和测试点原文件名保留。题库中未保存过的生成器、题解、暴力程序等原命题工程附件无法从系统导出。比赛、考号、成绩、学生提交及管理凭据不进入题包。

单题结构如下：

```text
library-manifest.json
<内部标识>/
  problem.json
  csp-package.json
  liteoj-seed.json
  题目.md
  标程.cpp             # 未保存标程时省略
  data/<原文件名>.in
  data/<原文件名>.out
  samples/<原样例文件名>
```

目标机器需要部署带 `csp-problem/1` 支持的本版本或后续兼容版本。单题 ZIP 在目标系统「新建题目」直接上传即可；批量 ZIP 解压后，每个题目文件夹都可以独立上传，无需重新填写限额。整包批量导入可使用现有题单导入 API 或命令行。系统先检查全部文件及清单，缺失、篡改、未声明文件、非法路径或不支持的格式会拒绝导入。校验通过只说明题包完整，不等于题目算法或答案经过审验。

新导入的教师题目编号按目标题库分配，以免冲突；原编号和原更新时间留在 `csp-package.json` 的来源信息中。内部标识和默认英文名随包保存；目标已存在相同内部标识时，「新建题目」自动另建一题，题单 API 默认跳过；要替换已有题请在该题详情选择「整题重传」，保留目标的题目编号。覆盖数据会撤回受影响的成绩、要求重测，在途评测时拒绝覆盖。按场次自定义的英文名仍以比赛配置为准。

题包目前使用本系统支持的普通标准判题和独立测试点计分。它不迁移机器专属的评测倍率、编译器版本或沙箱配置；目标评测环境需独立配置。`liteoj-seed.json` 供未来 LiteOJ 导入适配使用，尚不是 LiteOJ 一键上传接口。

HTTP 接口为 `GET /admin/problem-export?pid=<内部标识>`，要求教师会话 Cookie；兼容已有管理密钥认证。成功响应为 `application/zip`、下载附件和 `private, no-store`。不存在或已删除题目返回 404，题包不完整或超限返回 400。导出同时检查单题未压缩总量和 ZIP 大小，并预留 4 KiB 表单开销；上限由 `CSP_MAX_PS_UPLOAD_MB` 决定，默认 64 MiB。目标机器上传上限也须足够大。

在线批量导出使用 `POST /admin/problem-export`，URL 编码表单字段 `pids` 为逗号分隔的内部标识，也支持 `GET /admin/problem-export?pids=...`。认证和下载策略与单题一致。重复标识只导出一次；空选择、非法标识、已删除题或缺失题返回 400。每次最多 500 题、20,000 文件，未压缩总量与 ZIP 大小均受 `CSP_MAX_EXPORT_MB` 限制，默认 512 MiB。此设置不会增加题包上传上限；超过目标上传限制时，可解压后分题迁移，或由目标管理员调整上传上限。

「删除」先将题目移入回收区，仍可恢复。「彻底删除」使用页面内确认窗口，并清理正式数据、样例附件、SQLite 题面与元信息、兼容旧题面文件。操作期间复制该题文件并使用数据库事务；遇到文件或数据库错误时回滚并恢复副本。若恢复也失败，保留副本路径并明确报错，便于人工恢复。成功后清理临时副本；历史提交与成绩记录保留。被任何比赛引用的题目禁止彻底删除，须先从比赛配置移除。此恢复机制处理正常运行期间的错误，不等同于文件和数据库的断电原子事务；常规备份仍须保留。

批量离线导出仍使用 `csp_exam/tools/export_library.py`，停止 CSP 网站后运行；`--pid` 可重复，不传则导出全部未删除题目。不得将完整题包、答案或备份提交到公开仓库。
