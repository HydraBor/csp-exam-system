# 名单归属与排行榜筛选

名单分组可统一设置“校区”和“指导老师”，组内学生使用同一校区和一位老师。两个字段最多100个字符，留空时排行榜显示“未填写”。旧分组、旧考号和旧成绩仍可使用，不根据当前分组推测或补写历史归属。

从分组导入比赛时，将校区、指导老师及来源分组记录保存到本场名单；以后修改或删除分组不会改动既有比赛。临时粘贴名单也可以统一填写这批学生的校区与老师。每场按“姓名＋校区＋指导老师”识别学生：任一字段不同即为不同学生，分别生成考号；重复导入相同身份会保留原考号，同一身份来自多个分组时仍只报名一次。

重建或重新随机分配考号时保留归属和来源分组。已有学生开考或提交的场次仍禁止重建、重排和删除其考号。管理员可在比赛设置末尾展开“更正本场学生归属”，选择明确的学生与考号后修改两项归属。更正保留账号、考试起止时间、提交源码及成绩，不会改原分组或其他比赛；若更正后与本场另一名学生的完整身份重复，则拒绝保存，不自动合并考号或成绩。

考号打印表也显示校区、指导老师，便于将同名学生的考号分别发给正确对象。比赛设置与打印表的考试链接优先使用配置的公网HTTPS域名，不暴露回环后端端口。自建本地实例未配置公网域名时，使用当前请求的合法Host地址。

排行榜显示校区、指导老师、总排名和筛选内排名，支持两项组合筛选及姓名搜索。老师下拉框随所选校区列出相关老师，也可以筛选“未填写”。总排名始终保留全场位置，筛选内排名针对当前筛选与搜索结果重新计算，同分使用1、1、3式并列名次。未提交或未完成评测的学生不参与两种排名。“重置筛选”返回完整名单。

表格呈现使用[AG Grid Community与官方Quartz主题](排行榜组件接入.md)。前五列采用紧凑固定宽度，题目列分配剩余空间；长归属名称完整换行，列宽可调整，手机在表格内横向滚动。计分与排名规则仍由现有接口决定。

学生和管理员均可使用筛选。筛选只改变已获授权数据的展示，不提前开放成绩：未结束或未公布时，学生页面和公开JSON仍不含名单、归属、题目成绩或排名；管理员沿用原有鉴权与教师预览权限。公开投影不含考号、登录密码、来源分组或学生提交入口。归属更正会使排行榜版本/ETag失效，已有页面在下一次刷新时读取新信息。

校区和教师是SQLite中分组、比赛名单记录的字段，未新增数据库进程或文件存储。后台更正入口为管理员鉴权的 `POST /admin/roster-affiliation?c=<比赛ID>`，提交 `kaohao`、`campus`、`teacher`。更正不接受重发考号、改成绩或更改考试时长。

验收工具：`python3 -m unittest csp_exam.tests.selftest_affiliation`，以及Node.js运行`csp_exam/tests/selftest_scoreboard_filters.js`。临时UI验收可运行`python3 -m csp_exam.tests.preview_affiliation`；只监听127.0.0.1:18084，数据由TemporaryDirectory隔离，退出后清理。该工具的管理员模拟仅用于此临时服务器，不用于生产服务。
