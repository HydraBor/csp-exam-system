# 学生题目资源限制

学生考试中的题面标题下显示时间限制、内存限制和满分。考场题目列表在题名下用一行较小文字显示时限、内存，不额外扩展表格列。

读取与评测相同的题库限额，时限用秒显示，保留小数；内存使用MiB，256代表256×1024²字节。页面展示题目配置的基准时限，机器倍率仍由既有评测设置应用，不改题库、倍率或评分。缺失/非法配置显示“未配置”，不猜默认值。资源限额加入题面刷新版本，管理员仅改限额也会触发15秒轮询更新。

管理端题库列表、题目详情和自己测试的时限说明同样使用秒，2500毫秒显示为2.5秒。编辑字段和评测接口仍使用毫秒。

沿用现有Tabler 1.6.1卡片、徽章和datagrid组件，用弱化的文字标签、清晰数值和留白建立层次。标题可换行，资源项在窄屏重排，使用语义化dl/dt/dd对应标签与数值。

设计依据：

- [Tabler Data grid](https://docs.tabler.io/ui/components/datagrid)：标签/值成组展示，响应式栅格。
- [W3C WCAG 2.2 Reflow](https://www.w3.org/WAI/WCAG22/Understanding/reflow.html)：窄屏阅读不应丢失信息或产生不必要的双向滚动。现有多列表格仍在自身容器内滚动，资源信息不增加列数。

验证覆盖：真实HTTP读取题面及考场列表、仅修改限额后刷新版本改变、缺失限额不会伪造、开考前/结束后不泄露资源信息、未登录不可读取。使用独立临时数据，未接入生产评测。桌面浏览器和320/390像素宽度检查留白、字体和内容边界。
