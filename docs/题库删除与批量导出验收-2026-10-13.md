# 题库删除与批量导出验收（2026-10-13）

题库操作改用页面内确认窗口，消除对宿主浏览器原生 `confirm()` 展示的依赖。确认后显示进度与结果，取消不发请求。原实现忽略文件删除错误，且在数据清理失败后仍删除登记；现实现检查删除错误，使用 SQLite 事务和单题文件恢复副本，失败时恢复题目并明确报告异常。旧 Markdown 题面文件也会清理，被比赛引用的题目继续禁止彻底删除。

题库新增行复选框、全选、部分选择状态、数量提示和「批量导出 ZIP」。每题存入独立文件夹，使用现有完整题包格式，包含本系统保存的题面、标程、元信息、限额、正式数据、样例和哈希清单。公开样例与大样例保留原分类，仍不参与计分。批量下载默认上限 512 MiB，上传上限维持原设置；用法见 [题目导出与迁移](题目导出与迁移.md)。

本地实际检查结果：

- 22 套逻辑自测通过；新增删除恢复自测 10 项、导出自测 13 项通过。
- 删除检查覆盖文件权限失败、删了一半时失败、样例清理失败、SQLite 错误、在用题目、非法或缺失标识、相同前缀题目隔离，以及成功后旧题面和数据库清理。
- 导出检查覆盖多题完整迁移、重复选择、大小限制、学生及匿名鉴权、缺失或损坏文件、非法路径、并发限制、失败后释放导出槽位。解压后的各单题文件夹重新导入，逐题核对内容和正式点数量。
- 管理端 HTTP 回归：Linux 202 项、Windows（含 Node 内联脚本语法检查）246 项通过；新静态脚本 Node 语法检查通过。Windows 前端 8 项通过。
- 浏览器实际验证多选、全选、数量提示、三题 ZIP 下载、页面内删除确认和取消、恢复后的表格及勾选状态，无页面脚本错误。

测试使用隔离数据和虚构题目。服务器部署须保留业务备份，比较数据库内容、正式数据、样例、学生提交和既有服务状态；线上检查与恢复资料保存在私有运维目录，避免将题目、答案、凭据或学生资料放入源码仓库。
