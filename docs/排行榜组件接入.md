# 成熟排行榜组件接入

2026-10-15采用 **AG Grid Community 36.2.0** 与官方 **Quartz** 主题。它是MIT许可的表格组件；AG Grid负责表格绘制、列宽伸缩、表头、滚动、键盘操作及可访问性。平台继续提供经过权限检查的成绩、全场名次与筛选内名次，不引入另一套计分规则。

## 选型依据

| 候选 | 官方资料核查 | 本项目适用性 |
| --- | --- | --- |
| [XCPCIO](https://xcpcio.com/) | 独立竞赛榜单，主要采用ICPC通过题数、罚时和封榜 | 需要改写其计分及学生归属模型，不能直接作为本平台的OI分数榜 |
| [Hydro](https://github.com/hydro-dev/Hydro) | 完整OJ，含多种赛制和榜单 | 榜单与Hydro比赛、用户及记录模型相连；已有HydroJudge并不提供这一整套网站接口 |
| [AG Grid Community](https://github.com/ag-grid/ag-grid) | MIT免费版，支持原生JavaScript，官方现成主题与列布局；查询时仓库约1.56万星 | 适合直接嵌入现有服务端页面；不需要增加数据库、前端构建服务或另一台服务器 |
| [Tabulator](https://github.com/tabulator-tables/tabulator) | MIT表格组件，查询时仓库约7800星 | 同样可嵌入；本次采用AG Grid的Community主题和表格功能 |

热度是查询时的近似值，不能单独证明质量。本次选择还考虑既有接口、部分分排名、校区/教师属性、隐私控制及部署资源。

官方实现依据：[原生JavaScript快速接入](https://www.ag-grid.com/javascript-data-grid/getting-started/)、[列宽与flex](https://www.ag-grid.com/javascript-data-grid/column-sizing/)、[现成主题与参数](https://www.ag-grid.com/javascript-data-grid/theming-parameters/)、[自动行高](https://www.ag-grid.com/javascript-data-grid/row-height/)、[Community与Enterprise区别](https://www.ag-grid.com/javascript-data-grid/community-vs-enterprise/)。本次只使用Community功能。

## 页面与数据适配

前五列默认宽度依次为64、84、108、100、88像素，共444像素；总分为76像素。各题列的最小宽度为88像素，使用flex分配剩余宽度。列宽可拖动调整；长姓名、校区或教师名称完整换行，行高随内容增加。小屏在表格内部横向滚动，保留全部字段。

`scoreboard-grid.ag36.js`读取既有页面内经过转义的表头和成绩行，使用AG Grid显示。它只适配呈现，不发起新的成绩请求，不连接外部榜单服务。既有搜索、组合筛选、15秒刷新及管理员提交链接继续工作；表头或成绩行变化后自动同步。排名顺序保持由平台确定，禁止表头另行排序或移列，以免混淆总排名与筛选内排名。未公布或权限失效时清空组件的成绩行。

服务端表格作为基础呈现和组件加载失败时的退路；增强成功后从视觉与可访问性树隐藏基础表格，避免两份重复榜单。适配脚本由按请求读取的页面模板延迟加载，解决解析时机并方便热更新。非榜单页面立即返回，不加载AG Grid大文件。
