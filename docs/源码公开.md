# 赛后公开提交源码

每场比赛独立控制，默认关闭。管理员在本场管理页点击“开启源码公开”，只保存本场`public_sources`设置，不重排考号、不开始或重置计时、不改提交和成绩。

源码入口同时满足：本场开启源码公开、**整场**结束、成绩已公布。自主开考以最晚允许开考时间加个人时长作为整场结束时刻；提前考完或关闭允许开考时间窗均不会提前开放。关闭源码公开或收回成绩后，旧链接的预览和下载也立即拒绝访问。其他比赛不会随之开放。

公开排行榜的学生姓名可进入该生提交详情，各题分数可进入对应题目。展示每个测试点的判定、实际得分、用时和内存，以及与成绩对应的源码；没有逐点记录或编译未通过时明确说明，不虚构结果。访问和源码下载均不要求登录。页面沿用Tabler、响应式表格和已有代码预览、复制组件，排行榜沿用AG Grid及现有筛选；未交卷或未评测完毕者不生成入口。

OI展示判分使用的文件，IOI展示每题保留的最高分所对应的文件；IOI历史记录缺少对应源码路径时不以最近上传的另一份代码顶替。兼容已归档快照与原有考号前缀路径，找不到时明确提示无可公开源码。每个请求重新检查公开条件和当前报名，不能用旧链接读取撤回的公开内容。

只可读取本场、该生、该题服务端判分记录引用的C/C++或Pascal源码。逐点表严格只投影判定、得分、用时和内存，不直接复制原始评测对象或日志。不提供任意路径参数、不遍历上传目录、不公开姓名TXT、上传ZIP、测试输入、学生输出、标准输出、编译原始日志、编译产物或后台账号资料。源码正文按实际提交内容展示。公开URL使用独立签名的不透明标识，界面和API不暴露登录考号、上传路径、管理员密钥或评测账户；预览和下载禁止缓存。

公开查看仍走`/scoreboard?c=比赛编号&source=不透明标识`，指定`p`进入单题，`download=1`下载该题源码。普通排行榜及教师入口权限不变；`private=1`不能绕过源码的公开条件。

回归入口：`python -m unittest csp_exam.tests.selftest_public_sources csp_exam.tests.selftest_scoreboard csp_exam.tests.selftest_flexible_exam`。测试使用独立临时数据库和虚构学生，覆盖匿名访问、整场截止时间、关闭与撤回、非法标识、目录穿越、个人信息隔离、按成绩选源码、IOI路径缺失及管理开关鉴权。

补充回归覆盖管理端反复开启/关闭后的排行榜缓存失效、空文件与GBK源码原字节下载、二进制和超限文件拒绝访问，以及替换判分记录后分数、代码和逐点详情同时更新。“公布成绩”与“开启源码公开”是两个独立操作；只公布成绩不会生成源码链接。
