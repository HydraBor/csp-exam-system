# 自主开考

管理员在新建比赛或本场设置中选择「自主开考（每人独立计时）」，填写允许开考的起点、最后允许开考时间和每人的考试时长。原有比赛缺少模式字段时继续采用统一开考。

例如允许开考时间段为北京时间 08:00—18:00、考试时长 180 分钟：17:30 首次登录的考生立即开始，截止时间为 20:30。18:00 起不再接受首次开考；已经开考的人可以重登，继续使用剩余时间。全场成绩最早于 21:00 开放。

## 考生流程

- 时间段前凭考号登录，只显示比赛基本信息和倒计时，不显示题目，不开始个人计时。
- 倒计时到零后，页面自动显示「开始考试」。只有点击才开始计时；保持候考页打开不会自动开始个人考试。
- 时间段内第一次凭考号成功登录，则立即开考。
- 开考时间和截止时间以服务端为准，并存入 SQLite；退出、断网、刷新、多标签页以及服务重启不会暂停或重新起算。
- 个人考试截止后不能读题或提交，即使开考时间段尚未结束也不能再考一次。接收上传结束时再次检查截止时间，跨越截止的上传不归档、不进入评测。
- 成绩、编译与测试点反馈、排行榜全部等到「最后允许开考时间＋考试时长」之后统一开放。若仍有排队、失败或待重测记录，则待评测完整通过公布检查后开放。页面会自动刷新出成绩入口。

## 管理与存储

本场名单表显示每位考生的开考时间、截止时间和考试状态。首位学生开考后锁定时间段与个人时长；不能重建名单、重新随机发号，或者删除、变更已开考的考号。可继续追加新考生。已经开放的比赛不能切换开考模式。需要另一套时间或身份安排时新建比赛。

自主开考场自动公布成绩。老师可以主动收回成绩，收回后保持隐藏，直到老师重新公布。统一开考场继续使用原有的老师手动公布流程。

SQLite 由版本 1 升级为版本 2，新增 `exam_attempts(contest_id,kaohao,start_at,end_at)`，以比赛和考号联合唯一；不把计时存到 Cookie 或浏览器存储。首次开考与配置、名单读取在同一事务内，防止同时点击或修改配置获得重复时长。删除已结束的比赛时同步删除其计时记录，避免复用比赛编号时继承旧记录。

升级前须备份业务数据库。旧版本代码不认识版本 2，不可直接将代码切回旧版本继续使用新数据库；若升级启动失败，应在未接收新数据的前提下同时恢复升级前代码与数据库。已有新增考试数据时保留数据库，通过修复新版代码恢复服务。

## 验证

`csp_exam/tests/selftest_flexible_exam.py` 覆盖提前登录、手动开考、晚开考、重登、跨窗口提交、精确边界、并发重复开考、SQLite 升级、上传跨截止、成绩鉴权、自动公布和老师收回。`selftest_timer.js` 检查候考转为可开考时仅刷新出按钮，以及成绩解禁时自动刷新。
