# 考号查询

学生入口为 `/exam-number`，考试登录页提供“查询考号”按钮。界面参考 [OIerDb](https://oier.baoshuo.dev/) 的搜索、筛选布局，使用本项目已有的本地 Tabler 组件，没有复制其代码、选手数据或品牌资源。

用户已明确选择公开查询，无需登录或额外验证。姓名须完全匹配，去除首尾空格，不支持拼音、子串、通配符或空姓名列出全体。查询本身不会登录、开始个人计时、生成考号或改变任何业务记录。

1. 输入完整姓名并点击查询，取得该姓名在所有现存比赛报名快照中的校区、指导老师选项。
2. 选择校区后，指导老师列表只保留该校区真实匹配的老师；更换校区会清除原老师选择。两个选择均完成后才返回考号。
3. 列出完整身份匹配的全部场次，不以比赛是否结束、成绩是否公布过滤；显示名称、时间、状态、时长、考号、复制按钮和考试登录链接。不同场次的考号不会互相替换。

校区与老师取自比赛报名时的快照，不根据当前分组补写历史信息。旧记录缺少归属时仍可选择“未填写”。已删除的比赛和孤立名单不参与查询。后台更正归属或重新分配考号后，下一次查询立即读到当前数据，没有静态导出名单或陈旧客户端题库。

公开接口为 `POST /api/exam-numbers`，Content-Type 为 `application/json`，请求体最多4096字节。例如先传 `{"name":"测试学员"}` 获取筛选选项，再传 `{"name":"测试学员","campus":"深圳南山","teacher":"张老师"}` 获取考号。旧归属的空字符串与尚未选择（省略字段）明确区分。GET 不执行姓名查询；页面不把姓名放进地址栏，响应禁止缓存，查询页声明不被搜索引擎索引。

接口仅投影必要的报名与比赛信息，不返回评测站密码、管理密钥、UID、源码、提交、分数或排名。原有比赛权限和赛中零反馈规则继续生效。姓名、校区、老师可公开查出考号是用户明确批准的产品规则，不应误称为验证了查询者本人身份。

登录页保留本场考试名、考号输入、必要计时提示及登录/查询按钮，去除重复规则文字；报错内容先进行HTML转义。自主考试仍由单独的 `POST /start` 开始，查询入口和登录均不会启动计时。

验证：`python -m unittest csp_exam.tests.selftest_exam_numbers -v`。界面预览：`python -m csp_exam.tests.preview_exam_numbers`，只监听127.0.0.1:18085，全部记录为临时虚构数据，结束时请求 `POST /__preview-stop` 清理；生产服务没有该停止接口。
